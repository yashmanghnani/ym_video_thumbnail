# ym_video_thumbnail example

Run the example on Android API 24 or newer or iOS 15 or newer.
Use Flutter 3.50.1 and Dart 3.14.0 or newer.

```bash
cd example
flutter pub get
flutter run
```

Use the sample HTTPS URL or choose a video from the device. Tap **Data** to
generate thumbnail bytes or **File** to write an image to the app's temporary
directory. Camera capture requires a device with a camera and permission to use it.
